## Featured Projects

### [SplitUp — Multi-User Expense Manager](https://github.com/DhaanishNihaal/SplitUp-Multiuser_Expense_Manager)

> Full-stack group expense splitting app with real-time chat — **Splitwise meets WhatsApp**.

| | |
|---|---|
| **Backend** | Spring Boot 3.1, Spring Security (JWT), Spring Data JPA, WebSocket (STOMP + SockJS) |
| **Frontend** | React Native 0.81, Expo SDK 54, TypeScript, Expo Router |
| **Database** | PostgreSQL (Neon serverless) |
| **Deployment** | Render (Docker), Vercel (Web), Expo EAS (APK), UptimeRobot (monitoring) |

**Key Features:**
- Group expense tracking with automatic split calculation
- Greedy settlement engine that minimises the number of payments to settle up
- Real-time chat with typing indicators, online presence, and unread badges
- Group invite system with accept/reject flow
- Role-based access control (User, Moderator, Admin)
- Quick-pay settlement recording with net balance dashboard

[![View Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/DhaanishNihaal/SplitUp-Multiuser_Expense_Manager)
